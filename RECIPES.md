# PicAxe Mod - Crafting Recipes

This document contains all the crafting recipes for the PicAxe mod.

---

## **PicAxe Tool**

A magical axe used to store and apply image URLs.

```
 P 
PAP
 P 
```

* **P** = Pixel Dust
* **A** = Iron Axe

---

## **Image Configurator**

An advanced tool for detailed block configuration with tabbed interfaces.

```
PIP
ISI
RSR
```

* **P** = Pixel Dust
* **I** = Iron Ingot
* **S** = Stick
* **R** = Redstone

---

## **Pixel Dust** (x16)

A mystical powder used in all image-based crafting.

```
Redstone + Lapis + Diamond
```

* 4x Redstone
* 4x Lapis Lazuli
* 1x Diamond
  *(Shapeless recipe)*

---

## **Image Frame**

A highly configurable frame block with advanced positioning and transformation options.

```
GPG
PLP
GPG
```

* **G** = Glass Pane
* **P** = Pixel Dust
* **L** = Any Log

---

## **6-Sided Image Block**

Each face can display a different image, with optional lighting effects.

```
GPG
PLP
GPG
```

* **G** = Glass
* **P** = Pixel Dust
* **L** = Any Log

---

## **Image Shield**

Simply combine a **Shield** and an **Image Banner** in a crafting grid (shapeless).

---

## Recipe Notes

- All shaped recipes must be placed exactly as shown
- The shapeless recipes (Pixel Dust and Image Shield) can have ingredients placed in any arrangement
- "Any Log" means any type of log block (Oak, Birch, Spruce, etc.)
- Glass vs Glass Pane: Make sure to use the correct type as specified in each recipe
